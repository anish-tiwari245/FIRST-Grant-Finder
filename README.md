# FIRST Grant Finder

A searchable, filterable directory of grant and sponsorship opportunities for FIRST robotics teams (FLL, FTC, FRC).

## Goal
List every known grant and sponsorship opportunity for FIRST teams, filterable by:
- Type (grant / sponsorship)
- Program (FLL / FTC / FRC)
- State / region eligibility
- Deadline
- Rookie / veteran eligibility

## Tech
React + Vite + TypeScript, plain CSS (no UI framework).

## Status
Listing + filter page built against a local JSON data source (`data/opportunities.json`).
Save/bookmark and deadline-reminder features in progress.
